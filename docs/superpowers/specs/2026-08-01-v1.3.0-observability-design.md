# Design Spec: Milestone v1.3.0 (Observability & Telemetry)

## Overview
This specification addresses Issue #15 for Milestone v1.3.0:
- Integration of OpenTelemetry tracing/metrics exporter in `apps/control-plane-api/src/tracing.ts`.
- Addition of Prometheus & Grafana services in `docker-compose.yml`.

---

## 1. OpenTelemetry Exporter Configuration
- Update `apps/control-plane-api/src/tracing.ts`:
  - Import `NodeSDK` from `@opentelemetry/sdk-node`.
  - Import `OTLPTraceExporter` from `@opentelemetry/exporter-trace-otlp-http`.
  - Configure tracing exporter targeting `http://localhost:4318/v1/traces` (or `process.env.OTEL_EXPORTER_OTLP_ENDPOINT`).

## 2. Docker Compose Metrics Services
- Add `prometheus` (image: `prom/prometheus:v2.51.0`) and `grafana` (image: `grafana/grafana:10.4.0`) to `docker-compose.yml`.
- Create `prometheus.yml` with scrape target for `control-plane-api:3001`.
