# Design Spec: Milestone v1.1.0 (Security & Real-Time Logs)

## Overview
This specification addresses Issues #12 and #13 for Milestone v1.1.0:
1. **Issue #12**: Real-time deployment log streaming via WebSockets / SSE between `provisioner-worker` -> `control-plane-api` -> `backoffice-web`.
2. **Issue #13**: AES-256-GCM encryption for stored cloud credentials and SSH private keys in PostgreSQL.

---

## 1. Real-Time Log Streaming Architecture (Issue #12)

### Flow
```
[ provisioner-worker ] --( Redis Pub/Sub: 'deploy_logs:<id>' )--> [ control-plane-api (SSE Endpoint) ] --( Server-Sent Events )--> [ backoffice-web (EventSource UI) ]
```

### Details
- `provisioner-worker`: Whenever a log line is appended to a `Deployment`, publish a JSON payload `{ deploymentId, logLine, status }` to Redis channel `deploy_logs:<deploymentId>`.
- `control-plane-api`: Add `GET /v1/services/deployments/:id/stream` SSE (Server-Sent Events) endpoint in NestJS `services.controller.ts` using RxJS `Observable` subscribing to Redis Pub/Sub.
- `backoffice-web`: Update `apps/backoffice-web/src/app/(dashboard)/services/[id]/ClientPage.tsx` terminal viewer to connect via `EventSource` and append live streaming log chunks to the screen.

---

## 2. AES-256 Secret & SSH Key Encryption (Issue #13)

### Utility Module
- Create `apps/control-plane-api/src/common/crypto.util.ts` and `@organator/cloud-providers/src/crypto.ts` providing:
  - `encryptSecret(text: string): string` (Uses `crypto.createCipheriv('aes-256-gcm', key, iv)`)
  - `decryptSecret(encryptedText: string): string` (Uses `crypto.createDecipheriv('aes-256-gcm', key, iv)`)
- Environment key: `ENCRYPTION_KEY` (32 bytes hex key, fallback for dev).
