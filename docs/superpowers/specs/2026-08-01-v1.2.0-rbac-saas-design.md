# Design Spec: Milestone v1.2.0 (RBAC & SaaS Management Engine)

## Overview
This specification addresses Issues #14, #16, #17, and #18 for Milestone v1.2.0:
1. **Issue #16**: NestJS `RolesGuard` & `@Roles(...)` decorator.
2. **Issue #17**: Tenant Members CRUD API (`GET`, `POST`, `PATCH`, `DELETE` `/v1/tenants/members`).
3. **Issue #18**: Backoffice Web Members UI (Member list, invite modal, role selector, revoke access).
4. **Issue #14**: SaaS Engine (`QuotaGuard` for plan limits & usage tracking).

---

## 1. RolesGuard & @Roles() Decorator (Issue #16)
- Papéis suportados: `OWNER`, `ADMIN`, `DEVELOPER`, `VIEWER`.
- Create `apps/control-plane-api/src/auth/roles.decorator.ts`: `@Roles(...roles: string[])`.
- Create `apps/control-plane-api/src/auth/roles.guard.ts`: Checks `req.user.role`. If no `@Roles()` decorator is present, allow access. If present, enforce role hierarchy: `OWNER > ADMIN > DEVELOPER > VIEWER`.

---

## 2. Members Management API (Issue #17)
- Add endpoints in `apps/control-plane-api/src/tenants/tenants.controller.ts`:
  - `GET /v1/tenants/members` (List members for authenticated tenant).
  - `POST /v1/tenants/members` (Invite/add user to tenant with specific role).
  - `PATCH /v1/tenants/members/:userId/role` (Update member role).
  - `DELETE /v1/tenants/members/:userId` (Remove member from tenant).
- Restrict member modification endpoints to `@Roles('OWNER', 'ADMIN')`.

---

## 3. Members Management UI (Issue #18)
- Update `apps/backoffice-web/src/app/(dashboard)/tenants/ClientPage.tsx` or create a Members management tab:
  - Table of organization members with badges (`OWNER`, `ADMIN`, `DEVELOPER`, `VIEWER`).
  - Invite Modal with email input & role select.
  - Role change dropdown & remove button for each member.

---

## 4. SaaS Engine & Plan Quota Guard (Issue #14)
- Create `apps/control-plane-api/src/saas/quota.guard.ts` & `saas.service.ts`:
  - Plan limits:
    - `free`: Max 2 microservices, Max 5 deployments/month.
    - `pro`: Max 20 microservices, Max 100 deployments/month.
    - `enterprise`: Unlimited.
- Decorator `@CheckQuota('MICROSERVICE' | 'DEPLOYMENT')`.
- Return `402 Payment Required` with message `"Limite do plano atingido. Faça upgrade para continuar."` when limit is exceeded.
